前言

于是我打开 F12，想抄作业，但是…… Hexo 自动生成的这个 html 是啥啊，是给人看的吗

哦对哦它好像本来就不是给人看的……

突然想起来 Markdown 文件里面是能放 html 的，欸，这不就有了吗？

于是经过我的一番搜索，加上 ChatGPT 帮我写的 css，终于给我的博客也弄上了一个，当当当当！

OK，话不多说，开始发车！
