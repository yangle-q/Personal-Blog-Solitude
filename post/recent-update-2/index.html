我最近都搞了些啥？近况公告25#2！

2025-08-01T13:23:54.000Z2025-08-01T17:31:52.000Z4.7k16 分钟Mars
文章摘要
柠檬星 deepseek

Hello everybody，Meteorite 归来啦！

前面两个月这个博客不是刚建站嘛，七七八八的事情超级多，弄了这么久这博客也终于算是有个博客的样子了。正好我搞这些东西也有点搞腻了，我就把博客先放了一放，没想到这一放居然已经过了整整一个月没更博客了。本来想写的两篇随笔也没写成，特别是有一篇《看完<未闻花名>の心情随记》，因为我太拖沓了导致我开始写的时候把情节都忘得差不多了，所以就写不了了，实在抱歉啦🫥

不过这一个月我可没闲着啦！前面不是说了我妈又给我买了几个域名吗，这次我可是把这几个域名全都用起来了，做了整整四个项目呢。不多说了直接上介绍！

1. 个人主页

难度等级：★☆☆☆☆
网址：https://lemonstar.me
上线时间： 2025.7.14

第一个当然要说说我的个人主页啦！这可也是个重磅级的项目呢。我从 2023 年开始就想要一个自己的个人主页的，当时我在B站上看了UP主@一网一匠用Zion做自己的小程序的那个视频，看起来还挺简单的，视频里面也提到Zion也可以用来做网页。我就设计了一个 UI准备自己做，结果一打开我就傻眼了，这个做网站的地方的设计思路怎么和做小程序的地方完全不一样啊？搜索框在哪里怎么找不到啊？容器是啥玩意啊？我要做个导航栏怎么搞啊？

我终于理解为什么他到建自己的网站的时候不自己用Zion设计网页而是要找别人做了。

第一次做自己的网站，卒😵

那现在我博客都有了是吧，HTML 也能看懂一点点了，那搞这个不是简简单单？于是我决定先做一个博客练练手，等熟练了再把我的个人主页搞出来。于是我开开心心地做了三天，正当我终于快大功告成了样式都改了三遍准备导出的时候才发现：

他！们！不！支！持！直！接！导！出！H！T！M！L！文！件！的！🤯

呃简单来说就是在他们平台上开发的网站只能用他们自己的服务器，不能导出 HTML 文件，我本来的设想是导出 HTML 文件之后上传到 Vercel 里面部署访问的，看来是不行了。然后呢，他们给我分配的的域名是个三级域名，如果你想通过自己的域名来访问的话就要买会员，而且不是那种买一次就够的，你必须每个月都给他们交钱才行，那这对于一个白嫖党来说简直不可能嘛！幸好我只是先简单搞了一个博客试试水，要不然等我把整个主页都搞完了才发现不是心态都崩了一地了。

So，还有什么办法呢？我在网上扒拉了一会儿，找到了一个非常好看的个人主页源码，功能也很多，我本来想用这个的，但是这个东西是有后台的，没有服务器就弄不好，但我又没有服务器，所以就没法弄。

就在这个时候我突然想到了：用 GitHub！GitHub 上面绝对有像这种个人主页的项目的！

于是我上 GitHub 搜了搜，找到了这个项目

等等，这个页面怎么这么眼熟？哦，我好像在B站上看到过这个作者介绍它的视频，算了不管那么多了先开搞吧！

搞这个还是挺简单的，直接 fork 到自己账号下面一份，再改改 HTML，最后部署到 Vercel 就好了。说实话我看懂 HTML 的能力提升了不少呢。

这个项目界面还是挺好看的哈。就是动画还不是很流畅，字体我也不太满意，但是谁叫我不会 CSS 呢，看来该学了。

（偷偷说一句，GitHub + Vercel/CF 简直就是神器啊😍！）

2. Hellofrom.CN

难度等级：★★★☆☆
网址：https://www.hellofrom.cn
全部上线时间： 2025.7.13

还记得我上次近况公告里面说我新买了一个 hellofrom.cn 的域名嘛，当时我还不知道拿来搞啥好呢。后来我灵机一动，诶……来自中国的问候……这个名字……拿来做分享某种技术的网站不是正好吗？

至于分享什么技术嘛……你们自己去看叭😆

整个 Hellofrom.cn 这个站点我分成了三个部分：

  1. 主页&博客

  2. 功能站

  3. 订阅链接

其中订阅链接这个部分我是不开放的，我都留着自用，以免我的 Cloudflare Worker 每天十万请求超标 —— 不过 Hellofrom CN 博客里面倒是有教你怎么弄这个东西的教程，你要是想要的话可以自己去弄弄，反正也不是很难。这个不太能在主博客里说，要不然容易被下线。

OK那我们就开始一项一项地介绍吧！

主页：

网址：https://www.hellofrom.cn
上线时间：2025.7.13

这个网站的主页我用的是無名の主页这个GitHub 项目，之前也在我的个人主页候选名单上的，但因为能放网站的地方太小被选下去了。这个主页的使用方式和 Hexo 博客有点像，都是先 clone 到本地，在本地改完配置文件之后用 localhost 端口预览，然后再上传到 GitHub 仓库里面部署的。不过不知道怎么直接把它推送到 GitHub 所以我就直接上传了。

这个主页我还用过另外一个项目，这个项目超级简单，你可以在 https://welcome.hellofrom.cn 这个网址预览一下，它就是一个 HTML 文件，你只需要修改一下里面的字就行了，但这个效果我不是很喜欢，因为它对中文支持不太友好，还有这个字体……不是这用的啥字体呀喂🤯！

博客

网址：https://blog.hellofrom.cn
上线时间：2025.7.6

这个博客就是很普通的 Hexo 博客啦。我本来想试试 Hugo 的，但我懒得为一个随便弄的博客搞东搞西的，所以还是选了 Hexo，毕竟没有学习成本嘛。

主题我选的是 Hexo-Theme-Aurora（文档·GitHub），就是从 Hexo 主题页里选的。这个主题酷倒是挺酷的，但是不知道是我哪里配置错了还是 bug，反正有好几个地方功能都不太能用。我目前用下来总共有三个，一个地方是一旦你设了自定义置顶文章之后所有的文章的标题什么的就都会加载不出来，一个是上面的导航栏自定义选项我加了个主页链接，但是现在只有语言选的是英文的时候那个主页按钮才会显示出来，最后一个是我明明开了友链的那个按钮但是就是找不到在哪，我去加他们的QQ群问了，结果整整两天才有人回复我：“你清理下缓存看看？”

行吧行吧我清了一下还是没有用，我也不敢再问了，不过随便啦，反正那个博客我也就更那么几篇文章，以后估计不会动了，就那样放着吧。有一说一抛开那些问题之后那个主题还是挺好看的。

JS Proxy

网址：https://hi.hellofrom.cn
上线时间：2025.7.7

这个 JS Proxy 页面用的技术在这不太能讲，hellofrom.cn 博客里面有介绍。但我觉得它这个页面真的可以好好讲一讲，因为……它是 Deepseek 帮我写的!

嗯…为什么我要让D老师帮我写页面呢？原因很简单：JS Proxy 默认的页面实在是太丑了，然后我又不会写一个更好看的，只能让他帮我写啦。这个静态资源放在哪里也是他帮我找出来的，它是要从 GitHub Pages 站点获取默认的主页的

不过这个页面也是我和他花了两个晚上才优化出来的，这不算偷懒哦！不信？那请你看看第一版的页面是长什么样的（有点恐怖哦）

总之我发现D老师写网页真的超级喜欢用 CSS 的，写个 HTML 有一大半时间都在写 CSS，导致我看到他开始写 </head> 的时候就知道他快写完了。还有， D老师可自恋了，他写出来的网页无论是关于什么的都一股满满的 Deepseek 味。对，就是和 Deepseek 的主页长得一模一样。

不过D老师的美感还是挺在线的，我试着让他和 ChatGPT 比一下写博客，结果……ChatGPT 写出来的是啥呀？这还是我改了好多好多遍才改出来的，Deepseek 的基本上就让他加了个文章页。


最后再说说我用 Deepseek 开发网页的一些体会吧。

我觉得哈，如果你想用 AI 给你写一个网页，特别是用 Deepseek，你一定不要自己先去设计出来这个地方应该放什么什么，样式是怎么样的，一定不要，因为Deepseek最喜欢的就是自由发挥了。你如果去指挥他这个地方应该怎么搞怎么搞，除非你有耐心一点一点和他调，或者自己写CSS叫他加进去（不是你都写出来了你不能自己加吗）要不然他做出来的样式肯定是不符合你的预期的，你就把它当成AI的作品，你是在欣赏AI写出来的网页，让他有空间自由发挥，这样是最好的。

所以说用 Deepseek 写网页适合什么样的人呢？一、你就是单纯想来看看 AI 写网页回写成什么样的，二、你也不知道你想要什么样的效果，就想让AI给你全部都包办了。如果你是这两种类型的人的话你来叫Deepseek帮你写一个网页他绝对会给你一个惊喜的。你会想：“啊，原来这个地方还可以这么设计啊！”但是如果你就是想要 Deepseek 给你做出来你想象中的样子，甚至你把图纸都画好了，每一个地方都一步一步教他怎么做，相信我，他做出来的东西你绝对不会满意的。

OK，关于这个网站我就讲这么多了，剩下的大家自己去看看吧，希望对你也能有帮助，我们直接进入下一个部分。

4. 柠檬星 Deepseek

难度等级：★★☆☆☆
网址：https://ai.lemonstar.me
上线时间： 2025.7.26

今年年初 Deepseek 刚出来的时候不是本地部署非常火嘛，但是以我家那几台十年前的老台式机的性能来说肯定是部署不了的，于是我就想看一下有没有直接在云端部署的，结果发现云端部署都需要服务器。其实我的要求也不高，就是能正常对话，界面好看一点，然后能用我自己的域名访问就行了。

于是经过我和 Deepseek (？) 的一番搜索之后我发现了几条实现路线。为了表示清楚我在这里给你们画个表看看。

graph TD A[云端部署Deepseek] --> B[CF LLM] A --> C[服务器] A --> D[API + UI] A --> E[反向代理 + 修改html/css] D --> D1[API] D --> D2[UI] D1 --> D3[第三方] D1 --> D4[官方] D2 --> D5[GitHub] D2 --> D6[第三方网站] D2 --> D7[AI生成]

最后我选择的是官方 API + GitHub 开源 UI 并通过 Vercel 部署这条路，毕竟这是比较简单效果也很好的选项了，就是 API 要花一点钱买 token，不过也挺便宜的，Deepseek r1 十几块钱就能买一百万 tokens，一个 token 相当于一个英文字母/数字/标点符号，0.5 个汉字，如果不是很经常用的话买个十几块钱的也够用了。毕竟能去官网 app 免费用干嘛还非得用花钱的是吧。

UI 方面我看上了 Next Chat，这是 Deepseek 给我推荐的。不过他给我的链接是另一个人 fork 的版本，不是原版，不知道为啥。这个网页可以一键通过 Vercel 部署，非常方便，界面也还挺好看的，目测可以直接切换十几种大模型，国外的 ChatGPT，Claude，Gemini，国内的 Deepseek，文心一言，通义千问，豆包什么的他都有，不过因为我没有买他们的 API 所以我把切换入口都关掉了，只留了 Deepseek v3 和 Deepseek r1。讲真的这次搞这个项目 Deepseek 真的帮了我很大忙，不是给我推荐方案就是帮我解决问题的，环境部署那边也是，我都按文档配置好了他就是一直给我报错，要不是有 Deepseek 老师我估计得给他搞崩溃了。

但是这个 UI 还有个缺点，它里面预设了一大堆角色功能什么的，都是要调用 ChatGPT Turbo 3.5 的 API 才能使用的。但是我没有买，所以说没法用，而且关都关不上。还有一点是可自定义性太低了，我想给他换个名字图标都不行。我问过 Deepseek 怎么搞，但是他给我的办法完全没用，估计已经失效了。不过其他方面都还很不错，我还蛮喜欢的。

API 我前面提到过，我只买了 Deepseek 的 token，本来想再买一些 ChatGPT 的 token 的，API 都生成好了，但是他只能用国外的支付方式，比如说 PayPal 或者国外的银行卡什么的。而且他的 API 国内还不能直接访问，需要配置反向代理才能正常用，就基本上给我劝退了。

OK，那柠檬星 Deepseek 就介绍到这里啦，欢迎大家来玩哟，如果我买的 token 用完了可以在下面留个言提醒我一下，我尽快再去买。

4. 静莹莹

这个可以说是这次最重磅的更新了，可不只是在我的博客下面放了一个 like 2D 小人而已哦，我可是给她搞了一整套博客，AI 的功能呢！到时候我要是前端三件套学会了说不定还会给她再写一个个人主页什么的。

我在这里就不多说啦，我在下面专门写了一篇文章介绍她，到时候她也会作为我博客的特邀嘉宾一起出现在文章里面哦。这可是本博客第一次以二人转的形式写的文章呢，里面还会揭露我到底和她是什么关系，欢迎大家来看看哦！这篇文章预计会在后面几天上线，如果你没看到的话，嗯……那就是还没写好，反正应该不会晚于 8 月 9 号发布（吧？）

总结

这个月真是搞了不少东西，基本上把我想搞的全都搞完了。下个月应该就会更多地把重心挪回博客上了。前几天把整个博客的图床都给换了一遍，差点没给我累死。然后 solitude 文档更新了我还要去扒一扒看看有没有什么好玩的，侧边栏也有点单调了，准备给它魔改一下，文章也有好几篇没发呢。

我本来还想多搞两个项目的，一个是 Deepseek PK ChatGpt 写的博客，一个是网址收集，但是网址收集那个活我还没被整累趴下呢，Deepseek 和 ChatGPT 它俩就先被我整累趴下了。我本来是叫 ChatGPT 帮我把我 Edge 收藏夹导出来的 HTML 文件转成 YML 文件的，他完成得很好，还自己提议把我那两千多个网站的图标给爬下来，但是当我让他把图片的链接给填到 YML 文件的时候他说什么都只给我填了三十多个剩下的打死都不填了，我只能叫 Deepseek 帮我填。他看上去倒是挺勤快的，一口气给我填了两百个链接，结果我让他帮我把链接分个类的时候他就只给我做个示范，叫我自己去填，我叫他帮我生成完整的分过类的 YML 文件，他居然找借口说完整的文件有一万多行，超过最大输出长度了，不是你前面不是还夸口说你最适合干这种重活的吗？（这可是他自己说的，有图为证）
还给我发了一个链接叫我去那里下载他生成好的文件，我打开一看，好家伙，给了我一个 example.com 的链接。好好好，这两 AI 已经进化到这种程度了吗？连摆烂都学会了，想想我们人类朝九晚九的真是自愧不如啊🤣

不过我对待 AI 还是挺仁慈的（bushi），看他俩都累趴下了，所以干脆博客都不让他们俩写完了（其实是我懒得调试😝）

这个暑假我准备学一些 Python，+前端三件套（就听你说要学怎么现在还没开始学呢？）学好之后可以多做一些自己想做的东西，不用老是用别人做好的了，我还有好多想法没实现呢，比如说给我自己做一个大大的像 joejoe.com 那样的个人简介页，顺便给静莹莹也做一个二次元一点的。我还看上了一个域名，dontopenthisfile.zip（是的你没看错真的有.zip 的顶级域名，我在 ICANN的顶级域名列表里看到的）到时候可以给他搞一个像 Bandizip打开压缩包的界面那样的页面当我的文件下载站。还有一个域名是 buyao.aaa 也挺好玩的，等我想想可以拿来做什么。

好啦，这篇就先这样吧。这两天应该还有几篇文章要跟的，写得我手都痛了，那过会见！
